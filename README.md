# HubShark

A personal network toolkit for managing your own network connections.

## What is HubShark?

HubShark helps you set up and manage a personal network endpoint on
infrastructure you already own, with a companion app for your phone. It keeps
your connection settings organised, checks that your endpoint is healthy, and
lets you switch between saved setups in a few taps.

## Highlights

- Personal endpoint setup and management
- Health checks with automatic recovery
- Companion app with a simple dashboard
- Works with your own accounts — no third-party service required

## Getting started

Run the setup panel (`bash hubshark.sh`) or open the companion app and follow
the in-app help. Setup takes a few minutes.

HubShark builds on earlier personal network tooling work.
